The use of artificial intelligence in regards to this class has helped me understand OOP topics such as inheritance and has also helped shorten development time immensely. For example, in assignment #3 I was able to utilize Claude to refactor assignment 2's code, by having it change exactly what I requested it to change, which cut down development time. One time Claude made it difficult to learn was when it continues to try and improve code that's already been written. What I mean by that is, if I would write code and ask it something like "what design improvements do you think could be made to this?", it would give a list of improvements. But after implementing those improvements, it would come up with new improvements or even go back on some of the ones it suggested. Experiences like that are why you need to always double check what the AI is saying, and have the knowledge to be like "no actually, that change sucks". In the future, AI will always remain just a tool for developing, and should never act as the brain of the developer. I hope follow that ideology if a company would so graciously hire me.
